# hibernate-shortcut

Ярлык «Гибернация» на рабочем столе Windows: двойной щелчок — компьютер
засыпает с сохранением всех открытых программ, никакого меню «Пуск».

Гибернация — это не «спящий режим»: содержимое оперативной памяти
записывается на диск, компьютер полностью обесточивается и не тратит батарею,
а при включении все окна и вкладки возвращаются на место.

## Установка

1. Скачайте папку `hibernate-shortcut` на компьютер (кнопка **Code → Download
   ZIP** на странице репозитория, затем распакуйте архив).
2. Двойной щелчок по **`install.cmd`**.
3. Windows спросит разрешение администратора — нажмите **«Да»**. Права нужны
   только чтобы включить гибернацию, ярлык создаётся от вашего имени.
4. В окне появится строка «Готово» — нажмите Enter.

На рабочем столе появится ярлык **«Гибернация»**. Горячая клавиша —
**Ctrl + Alt + H** (работает, пока ярлык лежит на рабочем столе).

## Что делает установщик

* `powercfg /hibernate on` — включает гибернацию, если она была выключена
  (после чистой установки Windows и на ноутбуках с быстрым запуском она часто
  отключена);
* `powercfg /hibernate /type full` — переключает файл `hiberfil.sys` с
  «сокращённого» типа на полный: сокращённый обслуживает только быстрый запуск,
  самой гибернации при нём нет;
* создаёт на рабочем столе ярлык на `shutdown.exe /h` со значком, описанием и
  горячей клавишей. Окно консоли открывается свёрнутым, поэтому при щелчке
  ничего не мигает.

Ничего не устанавливается в систему, в автозагрузку не прописывается, фоновых
процессов не остаётся — только один `.lnk` на рабочем столе и настройка питания.

## Настройки

Запуск с параметрами — из PowerShell в папке со скриптом:

```powershell
# другое имя и своя горячая клавиша
.\install.ps1 -Name 'Спать' -Hotkey 'CTRL+ALT+S'

# без горячей клавиши
.\install.ps1 -NoHotkey

# только ярлык, настройки питания не трогать (администратор не нужен)
.\install.ps1 -KeepHibernateSettings

# свой значок: файл с иконками и номер иконки в нём
.\install.ps1 -Icon '%SystemRoot%\System32\imageres.dll,110'
```

Значок можно поменять и без скрипта: правый щелчок по ярлыку → **Свойства** →
**Сменить значок** → выбрать любую иконку из `shell32.dll` или `imageres.dll`.

## Удаление

Двойной щелчок по **`uninstall.cmd`** — ярлык с рабочего стола удаляется,
настройки питания остаются как были. Если при установке задавалось своё имя,
его нужно повторить: `.\install.ps1 -Uninstall -Name 'Спать'`.

Если нужно заодно выключить гибернацию и освободить место на диске (файл
`hiberfil.sys` занимает примерно 40% объёма оперативной памяти):

```powershell
.\install.ps1 -Uninstall -DisableHibernate
```

Учтите: вместе с гибернацией выключается и быстрый запуск Windows —
компьютер станет включаться медленнее.

## Если не работает

**Щёлкаю по ярлыку, а компьютер не засыпает.** Значит, гибернация в системе
недоступна. Проверить можно так: `Win+R` → `cmd` → в окне ввести

```
powercfg /a
```

Команда покажет, какие режимы сна доступны, а какие нет и почему. Частые
причины:

* **виртуальная машина** — гибернации там нет вообще;
* **запрещено политикой** на рабочем компьютере — нужен системный
  администратор;
* **не хватает места на системном диске** — файлу `hiberfil.sys` нужно
  примерно 40% объёма оперативной памяти;
* **старые драйверы видеокарты или чипсета** — обновите их с сайта
  производителя ноутбука.

**Компьютер сам просыпается по ночам.** Виноват не ярлык, а таймеры
пробуждения. Посмотреть, кто будит: `powercfg /waketimers`. Чаще всего это
сетевая карта — «Диспетчер устройств» → сетевой адаптер → **Свойства** →
**Управление электропитанием** → снять «Разрешить этому устройству выводить
компьютер из ждущего режима».

**Не срабатывает Ctrl+Alt+H.** Горячие клавиши ярлыков работают только для
ярлыков на рабочем столе и в меню «Пуск» — не переносите ярлык в другую папку.
Ещё сочетание может быть занято другой программой; задайте своё через
`-Hotkey`.

## Сделать то же самое вручную

Если запускать скрипты не хочется — всё то же делается руками:

1. **Включить гибернацию.** «Пуск» → набрать `cmd` → правый щелчок на
   «Командная строка» → **Запуск от имени администратора** → ввести:

   ```
   powercfg /hibernate on
   ```

2. **Создать ярлык.** Правый щелчок по пустому месту рабочего стола →
   **Создать** → **Ярлык** → в поле расположения вписать:

   ```
   shutdown /h
   ```

   → **Далее** → имя `Гибернация` → **Готово**.

3. **Горячая клавиша (по желанию).** Правый щелчок по ярлыку → **Свойства** →
   поле **Быстрый вызов** → нажать `Ctrl+Alt+H` → **ОК**.

Вместо `shutdown /h` иногда советуют
`rundll32.exe powrprof.dll,SetSuspendState 0,1,0`. Эта команда не открывает
окно консоли вовсе, но при выключенной гибернации молча уходит в обычный сон
вместо неё, поэтому здесь используется предсказуемый `shutdown /h`.

## Требования

Windows 10 или 11, Windows PowerShell 5.1 (входит в систему, ставить ничего не
нужно). Права администратора — только на этапе установки.
