# Бот записи на услуги

Телеграм-бот для барбершопа, маникюрного кабинета, репетитора — любого места,
где клиент выбирает время из свободных окон. Клиент записывается в четыре
нажатия, бот сам считает свободные слоты, напоминает о визите за час и даёт
отменить или перенести запись. Владельцу приходит уведомление о каждой записи.

```
Мужская стрижка · 1 ч · 1 500 ₽

Выберите день:
[ сегодня ] [ завтра ] [ Пт, 31 июл ]
[ ✖️ Сб, 1 авг ] [ Вс, 2 авг ] [ Пн, 3 авг ]

Свободное время:
[ 10:00 ] [ 10:30 ] [ 11:00 ]
[ 15:00 ] [ 15:30 ] [ 16:00 ]
```

## Что умеет

- **Считает слоты сам.** Из рабочих часов, длительности услуги и уже занятого
  времени. Услуга, которая не помещается до закрытия, в сетке не появится.
- **Не допускает двойной записи.** Проверка занятости и вставка идут одной
  транзакцией: пока клиент выбирал время, слот мог занять кто-то другой.
- **Напоминает за час.** Очередь напоминаний лежит в базе, поэтому перезапуск
  контейнера ничего не теряет.
- **Отмена и перенос — кнопками.** Отмена закрывается за N минут до визита:
  к этому моменту мастер уже отказал другим.
- **Несколько мастеров.** У каждого своё расписание и своя занятость; клиент
  может выбрать мастера или записаться к любому свободному.
- **Перерывы и выходные.** `/hours пн-пт 10:00-14:00 15:00-20:00`,
  `/dayoff 5.08 12.08 отпуск`.
- **Часовой пояс и переход на летнее время.** Внутри всё в UTC, наружу — в
  местном времени, поэтому сутки перехода не сдвигают записи.
- **Админка командами.** Расписание дня, услуги, мастера, часы, выходные,
  статистика — с телефона, между клиентами.

## Быстрый старт

### 1. Бот

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Узнайте свой user id у [@userinfobot](https://t.me/userinfobot) — это `OWNER_ID`,
   владелец точки и получатель уведомлений.

### 2. Настройки

```bash
cp .env.example .env
```

Обязательны два поля:

```ini
BOT_TOKEN=123456789:AAaa...
OWNER_ID=123456789
```

### 3. Посмотреть, как считаются слоты — без запуска бота

```bash
pip install -e .
python -m booking seed          # демо-услуги барбершопа и расписание
python -m booking slots         # свободное время на сегодня
python -m booking slots --day завтра
```

`seed` наполняет только пустую базу и ничего не затирает в рабочей.

### 4. Запуск

```bash
python -m booking run
```

Или в Docker:

```bash
docker compose up -d --build
docker compose logs -f
```

## Настройка под себя

Всё, кроме токена и часового пояса, задаётся из чата — файлы править не нужно.

### Услуги

```
/service_add Мужская стрижка | 60 | 1500 | мытьё, стрижка, укладка
/services
```

Формат: `название | минуты | цена | описание`. Обязательны первые два поля.
Услугу нельзя удалить — только скрыть: на неё ссылаются прошлые записи.

### Рабочие часы

```
/hours пн-пт 10:00-20:00
/hours сб 11:00-16:00
/hours вс выходной
/hours пн-пт 10:00-14:00 15:00-20:00     # с перерывом на обед
/hours                                    # показать текущее
```

Понимает `пн-пт`, `сб,вс`, `будни`, `выходные`, `все`.

### Мастера

```
/master_add Аня
/masters
```

Пока мастер один, бот не спрашивает клиента о выборе. Когда их несколько,
появляется шаг «к кому записать» с вариантом «не важно».

### Выходные и отпуска

```
/dayoff 5.08
/dayoff 5.08 12.08 отпуск
/dayoffs
```

Записи, уже стоящие на закрытые дни, бот не отменяет молча — только
предупреждает, решение за владельцем.

### Расписание и статистика

```
/today  /tomorrow  /week  /day 5.08
/stats
```

## Что видит клиент

| Кнопка | Что происходит |
| --- | --- |
| 📅 Записаться | услуга → мастер → день → время → подтверждение |
| 🗂 Мои записи | карточки с кнопками «Перенести» и «Отменить» |
| 💇 Услуги и цены | прайс с длительностью |
| 📍 Контакты | адрес и телефон из `.env` |

Телефон бот спрашивает один раз — при первой записи, кнопкой «Отправить
телефон». Дальше он подставляется сам.

## Правила записи

Задаются в `.env` и меняют поведение сетки слотов:

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `HORIZON_DAYS` | 14 | на сколько дней вперёд открыта запись |
| `SLOT_STEP_MIN` | 30 | шаг сетки: 30 — «10:00, 10:30, 11:00» |
| `MIN_LEAD_MIN` | 60 | нельзя записаться позже чем за час до начала |
| `CANCEL_DEADLINE_MIN` | 120 | когда закрывается самостоятельная отмена |
| `REMINDER_LEAD_MIN` | 60 | за сколько минут напоминать |

## Как устроено

```
src/booking/
  config.py        настройки процесса (.env)
  models.py        услуги, мастера, записи, окна расписания
  schedule.py      расчёт слотов и разбор команд вида «пн-пт 10:00-20:00»
  storage.py       SQLite: услуги, расписание, записи, клиенты
  service.py       сценарии: свободные дни, запись, перенос, отмена
  reminders.py     фоновый цикл напоминаний
  notify.py        уведомления администраторам
  texts.py         форматирование, единственное место с местным временем
  keyboards.py     клавиатуры и callback_data
  handlers/
    client.py      запись, свои записи, отмена, перенос
    admin.py       расписание, услуги, мастера, часы, выходные, статистика
```

Время внутри программы — всегда aware `datetime` в UTC; в местное оно
переводится только при выводе. Расчёт слотов вынесен в чистые функции без
базы и без Telegram — это самая ошибкоопасная часть, и она целиком покрыта
тестами.

## Тесты

```bash
pip install -e ".[dev]"
pytest -q
ruff check src tests
```

Тесты не ходят в сеть: расписание, хранилище и напоминания проверяются на
временной базе SQLite и подставном отправителе.

## Развёртывание

```bash
docker compose up -d --build
```

База лежит в `data/` — том смонтирован, переживает пересборку образа.
Бэкап — обычная копия файла `data/booking.db`.
