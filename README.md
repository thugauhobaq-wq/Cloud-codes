# Cloud-codes

## Проекты

* [`proposal-generator`](proposal-generator/) — генератор коммерческих предложений:
  веб-форма → PDF с логотипом клиента, сметой, НДС и суммой прописью. PDF
  собирается своим кодом, без внешних библиотек: Python stdlib + HTML/CSS/JS.
* [`reviews-dashboard`](reviews-dashboard/) — парсер отзывов о компании
  (Яндекс.Карты, 2ГИС, Wildberries, Ozon) с анализом тональности и веб-дашбордом.
  Без внешних зависимостей: Python stdlib + чистый HTML/CSS/JS.
* [`falling-blocks-3`](falling-blocks-3/) — лендинг «Лимонадная».
