# Cloud-codes

## Проекты

### Telegram-боты

* [`booking-bot`](booking-bot/) — запись на услуги (барбершоп, маникюр,
  репетитор): выбор свободного слота, напоминание за час, отмена и перенос.
  Расписание, услуги и выходные настраиваются командами из чата.
* [`shop-bot`](shop-bot/) — магазин с каталогом и корзиной: витрина для
  продавца без сайта, заказ в несколько нажатий, уведомление владельцу с
  кнопками «принять» и «отменить», учёт остатков и выгрузка заказов в CSV.
* [`leadmagnet-bot`](leadmagnet-bot/) — выдача лид-магнита по кодовому слову:
  сбор базы подписчиков, метки источников в ссылках, догоняющее сообщение
  через сутки и рассылка по собранной базе.
* [`freelance-parser`](freelance-parser/) — парсер заказов с фриланс-бирж
  (Kwork, FL.ru, Habr Freelance, Weblancer) с доставкой в Telegram и
  настройкой фильтров командами бота.

Все боты на aiogram 3 и SQLite, разворачиваются одной командой
`docker compose up -d --build`, состояние живёт в примонтированном `data/`.

* [`botkit`](botkit/) — каркас для новых ботов: настройки, хранилище с
  транзакциями, рассылка, фоновые воркеры, запуск с корректной остановкой.
  `python -m botkit new shop --push repo` создаёт работающий бот с тестами,
  Docker и CI — и кладёт его в GitHub.
* [`botfactory`](botfactory/) — бот, который делает ботов: «сделай бота для
  магазина, название Магазин у дома» в Telegram → ссылка на репозиторий с
  готовым проектом. Отдельным репозиторием или веткой в этом — на выбор.

### Документы

* [`proposal-generator`](proposal-generator/) — генератор коммерческих
  предложений: веб-форма → PDF с логотипом клиента, сметой, НДС и суммой
  прописью. PDF собирается своим кодом, без внешних библиотек: Python stdlib +
  чистый HTML/CSS/JS.

### Отзывы

* [`reviews-widget`](reviews-widget/) — виджет отзывов для чужого сайта: карусель
  ставится одной строчкой `<script>`, отзывы собираются формой и Telegram-ботом
  и проходят модерацию. Python stdlib + чистый JS, Shadow DOM.
* [`reviews-dashboard`](reviews-dashboard/) — парсер отзывов о компании
  (Яндекс.Карты, 2ГИС, Wildberries, Ozon) с анализом тональности и веб-дашбордом.
  Без внешних зависимостей: Python stdlib + чистый HTML/CSS/JS.
