# Бот выдачи лид-магнита

«Напишите кодовое слово — получите чек-лист». Бот отдаёт материал, собирает
базу подписчиков, показывает, с какой площадки пришли люди, догоняет их через
сутки и умеет рассылать по собранной базе. Простая механика, но это
работающая воронка — ровно то, что заказывают SMM-специалисты.

```
Пользователь: ЧЕКЛИСТ
Бот:          📎 Чек-лист запуска рекламы.pdf

через сутки:  Как дела с чек-листом? Если застряли
              на аналитике — напишите, подскажу.
```

## Что умеет

- **Понимает людей, а не только точный текст.** «Чек-лист», «ЧЕКЛИСТ»,
  «чеклист!», «/чеклист», «чёклист» — всё это одно кодовое слово. Воронка не
  теряет людей на опечатках.
- **Ссылки с метками источника.** `t.me/bot?start=чеклист__instagram` выдаёт
  материал сразу при запуске, а в статистике видно, какая площадка сработала.
- **Проверка подписки на канал.** Необязательная: если бот не может проверить
  (его забыли сделать админом канала), материал всё равно выдаётся — обещание
  из поста важнее.
- **Догоняющее сообщение.** Второе касание через N часов после выдачи, свой
  текст на каждый материал. Очередь в базе, перезапуск ничего не теряет.
- **Рассылка с предпросмотром.** По всей базе или только по получившим
  конкретный материал; темп держится ниже лимита Telegram, заблокировавшие
  бота помечаются и больше не беспокоятся.
- **База не теряется.** Заблокировавшие остаются в статистике, вернувшиеся
  автоматически возвращаются в рассылку. Выгрузка в CSV — одной командой.
- **Материалы любого вида:** текст, ссылка, файл, картинка.

## Быстрый старт

### 1. Бот

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен
   и имя бота.
2. Узнайте свой user id у [@userinfobot](https://t.me/userinfobot).

### 2. Настройки

```bash
cp .env.example .env
```

```ini
BOT_TOKEN=123456789:AAaa...
BOT_USERNAME=my_leadmagnet_bot
OWNER_ID=123456789
```

`BOT_USERNAME` нужен, чтобы бот собирал ссылки для постов.

### 3. Посмотреть без запуска

```bash
pip install -e .
python -m leadmagnet seed       # демо-материалы SMM-воронки
python -m leadmagnet magnets    # материалы и готовые ссылки
python -m leadmagnet stats 30
```

### 4. Запуск

```bash
python -m leadmagnet run
```

Или в Docker:

```bash
docker compose up -d --build
docker compose logs -f
```

## Как завести материал

```
/magnet_add чеклист | Чек-лист запуска рекламы | текст материала
```

Формат: `кодовое слово | название | текст`. Текст можно не указывать, а
вместо него прислать файл — картинкой или документом с подписью:

```
/magnet_file чеклист
```

Догоняющее сообщение:

```
/followup чеклист | Как дела с чек-листом? Отвечу на вопросы.
```

Ссылки для постов:

```
/link чеклист instagram vk telegram
```

Бот вернёт по ссылке на каждую площадку. Метка попадает в статистику, и
через неделю видно, откуда люди приходят на самом деле.

| Команда | Что делает |
| --- | --- |
| `/magnets` | список; нажатие включает и выключает материал |
| `/magnet_del чеклист` | удалить материал (подписчики остаются) |
| `/leads` | сколько собрано и кто пришёл последним |
| `/export` | выгрузка базы в CSV |
| `/stats` | воронка за 30 дней, `/stats 7` — за неделю |
| `/broadcast текст` | рассылка по всей базе |
| `/broadcast_to чеклист текст` | только получившим этот материал |
| `/broadcasts` | история рассылок |

Рассылка сначала показывает предпросмотр и число получателей и уходит только
после подтверждения: отправленное не отзовёшь, а опечатку увидит вся база.

## Проверка подписки на канал

Классический вариант воронки — «подпишись и получи». Включается двумя
строчками в `.env`:

```ini
REQUIRED_CHANNEL=@my_channel
CHANNEL_URL=https://t.me/my_channel
```

Бот должен быть **администратором канала** — иначе Telegram не даёт проверять
подписчиков. Если проверка не срабатывает по техническим причинам, материал
выдаётся всё равно: закрывать людям доступ к обещанному из-за своей ошибки
хуже, чем пропустить неподписанного.

Для приватного канала `CHANNEL_URL` обязателен — публичного адреса у него нет,
и кнопку «Подписаться» построить не из чего.

## Что видит подписчик

| Действие | Ответ бота |
| --- | --- |
| перешёл по ссылке из поста | материал приходит сразу |
| написал кодовое слово | материал |
| написал что-то другое | подсказка со списком слов |
| `/my` | что уже получал — если файл потерялся |

Длинные сообщения бот кодовым словом не считает: отвечать «не знаю такого
слова» на «спасибо!» — плохая идея.

## Как устроено

```
src/leadmagnet/
  config.py      настройки процесса (.env)
  models.py      магниты, подписчики, выдачи, рассылки
  codes.py       нормализация кодовых слов и разбор deep-link
  storage.py     SQLite: магниты, база, выдачи, рассылки
  delivery.py    выдача материала и проверка подписки
  broadcast.py   движок рассылки с темпом и обработкой блокировок
  followups.py   догоняющие сообщения
  texts.py       приветствие, списки, статистика
  keyboards.py   кнопки
  handlers/
    client.py    вход по ссылке, кодовые слова, проверка подписки
    admin.py     материалы, ссылки, база, рассылки, статистика
```

Отправка в рассылке и догоне вынесена в подставляемую функцию — движок с его
темпом, подсчётами и обработкой блокировок проверяется тестами без Telegram.

## Развёртывание

```bash
docker compose up -d --build
```

База лежит в `data/` — том смонтирован, переживает пересборку образа.
Бэкап собранной аудитории — обычная копия файла `data/leadmagnet.db`; делайте
её регулярно, восстановить базу подписчиков неоткуда.
