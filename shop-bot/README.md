# Бот-магазин с каталогом и корзиной

Витрина для маленького продавца, у которого нет сайта: каталог с фото и
ценами, корзина, оформление заказа и уведомление владельцу в тот же момент.
Товары, цены и остатки заводятся прямо из чата — ни админки, ни хостинга,
ни правки файлов.

```
🛒 Корзина

Эфиопия Иргачеффе, 250 г
    2 × 890 ₽ = 1 780 ₽
Воронка V60, керамика
    1 × 1 450 ₽ = 1 450 ₽

Товары: 3 230 ₽
Доставка бесплатно 🎉

[ ✅ Оформить заказ ]
[ 🛍 Каталог ]  [ Очистить ]
```

## Что умеет

- **Каталог с категориями и фото.** Листается страницами, пустые категории в
  витрине не показываются.
- **Корзина живёт в базе.** Покупатель складывает товары неделю, а бота за это
  время перезапустят не раз — корзина переживает и то, и другое.
- **Остатки.** Заказ списывает товар, отмена возвращает. Распроданное само
  исчезает из витрины; для услуг и печати под заказ учёт можно отключить.
- **Ничего не продаётся дважды.** Проверка остатка и списание идут одной
  транзакцией: между «положил в корзину» и «подтвердил» проходят часы.
- **Цены в заказе не «плывут».** Название и цена копируются на момент покупки:
  товар подорожает, а в заказе останется то, что видел покупатель.
- **Доставка и самовывоз.** Стоимость доставки, порог бесплатной, минимальная
  сумма заказа — в настройках; бот сам подсказывает, сколько добрать до
  бесплатной доставки.
- **Заказ владельцу с кнопками.** Принять, отменить, отметить выполненным —
  покупатель получает уведомление о каждом изменении.
- **Выгрузка в CSV.** `/export` — файл, который открывается в Excel без
  кракозябр.

## Быстрый старт

### 1. Бот

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Узнайте свой user id у [@userinfobot](https://t.me/userinfobot) — это
   `OWNER_ID`, вам будут приходить заказы.

### 2. Настройки

```bash
cp .env.example .env
```

Обязательны два поля:

```ini
BOT_TOKEN=123456789:AAaa...
OWNER_ID=123456789
```

### 3. Посмотреть витрину без запуска бота

```bash
pip install -e .
python -m shop seed        # демо-каталог кофейни
python -m shop catalog     # что получилось
python -m shop orders      # последние заказы
```

`seed` наполняет только пустую базу и ничего не затирает в рабочей.

### 4. Запуск

```bash
python -m shop run
```

Или в Docker:

```bash
docker compose up -d --build
docker compose logs -f
```

## Наполнение каталога

Всё делается командами в чате с ботом — от лица владельца.

```
/category_add Кофе в зёрнах
/product_add Эфиопия Иргачеффе, 250 г | 890 | Кофе в зёрнах | цитрус, жасмин | 12
```

Формат товара: `название | цена | категория | описание | остаток`.
Обязательны только название и цена. Категория ищется по названию, а если
такой нет — заводится сама.

Фото: пришлите картинку с подписью `/photo 12`, где 12 — номер товара из
`/products`.

| Команда | Что делает |
| --- | --- |
| `/products` | список; нажатие скрывает товар или возвращает в продажу |
| `/price 12 1290` | новая цена |
| `/stock 12 5` | остаток; `/stock 12 -` снимает учёт |
| `/lowstock` | что заканчивается |
| `/categories` | категории, нажатие скрывает |
| `/orders` | новые и принятые заказы карточками с кнопками |
| `/orders all` | последние 20 любых |
| `/order 12` | конкретный заказ |
| `/export` | выгрузка заказов в CSV |
| `/stats` | продажи за 30 дней |

## Что видит покупатель

| Кнопка | Что происходит |
| --- | --- |
| 🛍 Каталог | категории → товары → карточка с фото |
| 🛒 Корзина | количество кнопками ➖ ➕, удаление, оформление |
| 📦 Мои заказы | статусы и состав |
| 📞 Контакты | адрес самовывоза и контакты из `.env` |

Оформление: имя → телефон (кнопкой «Отправить телефон») → самовывоз или
доставка → адрес → комментарий → подтверждение. Имя, телефон и адрес
запоминаются, при следующем заказе бот их не переспрашивает.

## Правила магазина

Задаются в `.env`:

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `DELIVERY_PRICE` | 300 | стоимость доставки |
| `FREE_DELIVERY_FROM` | 3000 | сумма бесплатной доставки; 0 — не применять |
| `MIN_ORDER` | 0 | минимальная сумма заказа; 0 — без порога |
| `PICKUP_ADDRESS` | — | адрес самовывоза; пусто — только доставка |
| `DELIVERY_ENABLED` | true | выключите, если возите только самовывозом |
| `PAGE_SIZE` | 6 | товаров на странице каталога |
| `TRACK_STOCK` | true | списывать остатки и прятать распроданное |

Минимальная сумма считается по товарам, без доставки: иначе порог
«набирался» бы за счёт доставки, что покупателя только злит.

## Как устроено

```
src/shop/
  config.py      настройки процесса (.env)
  models.py      товары, корзина, заказ
  pricing.py     доставка, порог бесплатной, минимальный заказ
  storage.py     SQLite: каталог, корзины, заказы, покупатели
  notify.py      уведомления владельцу и покупателю
  texts.py       карточки товара, корзины и заказа
  keyboards.py   витрина, корзина, оформление
  handlers/
    client.py    каталог, корзина, оформление, свои заказы
    admin.py     товары, категории, заказы, остатки, выгрузка
```

Деньги — целые числа в рублях: копейки маленькому продавцу не нужны, а float
в деньгах рано или поздно даёт «1 499.9999999».

## Тесты

```bash
pip install -e ".[dev]"
pytest -q
ruff check src tests
```

Тесты не ходят в сеть: каталог, корзина, остатки и арифметика заказа
проверяются на временной базе SQLite.

## Развёртывание

```bash
docker compose up -d --build
```

База лежит в `data/` — том смонтирован, переживает пересборку образа.
Бэкап — обычная копия файла `data/shop.db`.
